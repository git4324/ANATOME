This application uses the browser-optimized BodyParts3D 4.0 geometry prepared by the Human Atlas project (https://github.com/ashemag/human-atlas). Adaptations include conversion to meter/Y-up coordinates, geometry simplification, quantized normals, and binary chunk packaging. The model represents an adult male reference anatomy and is provided for educational use, not clinical diagnosis.
